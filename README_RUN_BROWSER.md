# Smart Helmet 5.0 — Predictive Mesh Mine Safety Web App

Это браузерная версия прототипа. Python, Streamlit, FastAPI и установка библиотек не нужны.

## Как открыть

1. Распакуйте ZIP-папку.
2. Откройте файл `index.html` двойным кликом.
3. Нажмите `Старт`.

Если браузер блокирует локальные файлы, откройте папку проекта в терминале и выполните:

```bash
python -m http.server 8000
```

Потом откройте:

```text
http://localhost:8000
```

## Что исправлено в этой версии

- Всплывающее окно при наведении больше не обрезается снизу: оно фиксируется относительно окна браузера и автоматически смещается вверх/влево, если не помещается.
- Оставлен режим встроенной симуляции. Кнопка `Встроенная симуляция` возвращает демо-данные, даже если до этого был загружен CSV.
- `Сброс` также возвращает встроенный predictive-сценарий.
- `Авария в E` запускает встроенный аварийный сценарий.
- `Загрузить CSV` — дополнительный режим, а не обязательный.

## Как использовать

- `Старт` — запускает симуляцию.
- `Пауза` — останавливает время.
- `Сброс` — очищает состояние и возвращает встроенную симуляцию.
- `Встроенная симуляция` — включает обычный predictive-сценарий с постепенным ростом риска.
- `Сбой узла 3` / `Сбой узла 4` — имитирует потерю mesh-узла. Схема перестраивает маршруты через резервные связи.
- `Авария в E` — запускает аварийный сценарий в забое E.
- `Загрузить CSV` — можно загрузить внешний файл с показателями датчиков.

## Цвета

- Зеленый — безопасно.
- Желтый — потенциально опасно.
- Красный — опасно или потеря связи.
- Голубые пунктирные линии — резервный mesh-обход.
- Маленькие точки — шахтеры со Smart Helmet 5.0.
